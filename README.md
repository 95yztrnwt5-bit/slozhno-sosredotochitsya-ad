# Сложно сосредоточиться

Адаптивная страница с тремя цветовыми темами: «День», «Неон» и «Авто» (по настройкам системы). Проектная работа 3 спринта.

## Что реализовано

- Адаптивная вёрстка (mobile first) для ширины 375, 768 и 1440px
- Переключение тем: светлая, тёмная и автоматическая по `prefers-color-scheme`
- Выбранная тема сохраняется в `localStorage`
- Галерея изображений на CSS Grid
- Шрифт IBM Plex Mono

## Технологии

HTML, CSS (переменные, Grid, медиазапросы), JavaScript

## Структура проекта

- `index.html` — страница
- `styles/` — стили (шрифты, переменные, основные стили, темы)
- `scripts/` — переключение тем
- `fonts/` — шрифты
- `images/` — изображения и иконки
